# N02 — Accepted hyperscaler evidence

Research date: 2026-10-11.

Full returned brief: [hyperscalers.md](../hyperscalers.md).
Question: How do hyperscalers check GPU fabrics and run fabric diagnosis?
State: done. The state shows research acceptance, not fabric PASS.

- [observed] AWS EFA uses aws-ofi-nccl and Libfabric EFA. Its guide shows provider logs and a launch command (§2.1).
- [observed] Azure ND H100/H200 shows dedicated InfiniBand/GDR. An official NCCL sample shows test output (§2.2, §10).
- [observed] A3 High/Edge uses TCPX. Mega uses TCPXO. Ultra uses RoCE/MRDMA/gIB (§2.3, §11).
- [observed] A4X Max uses NVLink across 18 instances and 72 GPUs. RoCE runs inter-subblock traffic (GB300 addendum).
- [observed] NCCL 2.21+ dynamic GID guidance and one provider-specific forced-GID workaround show different methods (§12).
- [inference] Keep commands, versions, images, counters, topology, and selected transport fixed (§3–8).

Primary evidence: [AWS](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/efa-start-nccl.html),
[Azure](https://learn.microsoft.com/en-us/azure/virtual-machines/nd-h100-v5-series),
[Google](https://docs.cloud.google.com/compute/docs/gpus/gpu-network-bandwidth).
