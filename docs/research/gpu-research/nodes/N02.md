Question: Which GPU diagnosis steps do hyperscalers show?
Dependencies: None. State: done.

[observed] Google shows DCGM memory diagnosis and detailed XID recovery guidance.
Its detailed table shows contained and uncontained memory errors separately.
[Source](https://docs.cloud.google.com/compute/docs/troubleshooting/troubleshooting-gpus).

[observed] AWS uses automatic recovery for system-status failures on eligible instances.
It does not show GPU arithmetic correctness.
[Source](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ec2-instance-recover.html).

[observed] Named DCGM plugins can use duration overrides and overall timeouts.
A plugin override does not show an entire numbered suite's maximum duration.
[Source](https://docs.nvidia.com/datacenter/dcgm/latest/reference/command-line-reference/dcgmi/dcgmi-diag.html).

[inference] Keep event timelines. Do not use automatic resets during evidence collection.
Use each host's expected GPU count. Check 72 GPUs at rack level.
